Interactive OSI Layer & Packet Encapsulation Model

Understand how user data gets wrapped in headers at each network layer (Encapsulation) on transmission, and stripped off (Decapsulation) upon reception.

Layer 7 • Application Layer HTTP, DNS, TLS, SSH

Generates raw data payload (e.g., HTTP GET string or DNS hostname request).

Layer 4 • Transport Layer TCP / UDP

Adds Source/Dest Ports, Sequence Numbers, Flags (SYN/ACK), CRC checksum.

Layer 3 • Network Layer IPv4 / IPv6

Adds Source & Destination IP addresses, TTL (Time To Live), Protocol ID.

Layer 2 • Data Link Layer Ethernet II / Wi-Fi

Encapsulates in Ethernet frame with Source/Destination MAC physical addresses.

Layer 1 • Physical Layer Copper / Fiber / Radio

Converts frame bytes into electrical pulses, optical signals, or radio waves.

TCP vs UDP Protocols

TCP (Transmission Control Protocol) is connection-oriented, reliable, and guarantees in-order delivery via handshakes (SYN, SYN-ACK, ACK) and retransmissions. Used for Web (HTTP), Email, SSH.

UDP (User Datagram Protocol) is connectionless and lightweight. It prioritizes speed over reliability without handshakes or error recovery. Used for Video Streaming, Gaming, DNS.

DNS Lookup Architecture

Computers communicate via IP addresses (e.g. 198.51.100.100), but humans use domain names (example.com). The Domain Name System (DNS) acts as the internet's phonebook, translating human domain names into IP addresses via fast UDP queries.

Firewalls & Access Control

Firewalls examine packet headers (Source/Dest IP, Port numbers, Protocols) against Security ACL rules. If traffic violates policies or targets restricted ports, the packet is instantly dropped or rejected.

Content Delivery Networks (CDN)

CDNs place edge server caches geographically closer to users. Instead of routing traffic all the way to an origin web server across the globe, requests are served directly from the nearest CDN node, drastically reducing network latency and round-trip time (RTT).
